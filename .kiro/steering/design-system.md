# 비주얼 디자인 시스템 (결과 화면·지도)

`frontend-ui.md`의 배치·상태·표기 규칙 위에 얹는 **보는 느낌** 규칙이다. 두 문서가 충돌하면 `frontend-ui.md`를 따르고, 이 문서를 고친다.

## 톤

- Kiro 해커톤 톤의 보라색 + 둥글고 귀여운 느낌.
- 귀여움은 제목과 모양에만 쓴다. 시간·요금 숫자는 또렷하게 읽혀야 한다.

## 색 토큰

CSS Module 맨 위에 변수로 모아 두고, 컴포넌트에 색 값을 직접 쓰지 않는다.

| 변수 | 값 | 용도 |
|---|---|---|
| `--primary` | `#8E44D4` | 추천 카드 배경, 추천 배지, 주요 버튼 (`frontend-ui.md` 값 유지) |
| `--on-primary` | `#FFFFFF` | primary 위 글자 |
| `--primary-text` | `#7A35C4` | 흰 바탕 위 보라 글자 (총비용 금액, 보조 버튼 글자) |
| `--primary-soft` | `#F3EAFC` | 추천 행 배경, 연한 칩 배경 |
| `--surface-tint` | `#F6F2FD` | 스켈레톤, 지도 바탕 |
| `--ink` | `#1E1433` | 본문 글자 |
| `--text-sub` | `#5E5670` | 보조 글자 |
| `--border` | `#E6DDF6` | 카드 테두리, 표 줄 |
| `--ok` | `#16A34A` | 제시간 도착 |
| `--late` | `#DC2626` | 지각, 오류 |
| `--late-row` | `#6B7280` | 제시간 도착 불가 행 글자 |
| `--subway` | `#2E9E4F` | 지하철 구간 |
| `--taxi` | `#F2A007` | 택시 구간. 선과 채움에만 쓰고 글자색으로 쓰지 않는다 |

- 글자는 흰 바탕 대비 4.5:1 이상이어야 한다. `frontend-ui.md`의 `#9CA3AF`는 이 기준에 못 미치므로 글자에 쓰지 않고 선·아이콘에만 쓴다.
- 보라는 의도된 브랜드 색이다. AI 디자인 검사 도구(unslop)가 보라를 지적하면 해당 줄에 `unslop-ignore` 주석을 단다.

## 글꼴

| 용도 | 글꼴 |
|---|---|
| 추천 문장, 상태 제목, 섹션 제목 | **Jua** (굵기 400 하나뿐. 굵게 지정하지 않는다) |
| 본문, 표, 숫자, 버튼 | 기존 본문 글꼴 |

- Jua는 `next/font/google`로 결과 영역 안에서만 불러온다. `layout.tsx`, `globals.css`는 고치지 않는다.
- 숫자(시간·요금·도착 시각)는 Jua로 쓰지 않고 `tabular-nums`로 자리를 맞춘다.
- Jua는 같은 크기에서 작아 보이므로 다른 제목보다 2~4px 크게 쓴다.

## 모양

- 모서리: 카드 16px, 추천 카드 20px, 버튼 12px, 입력·표 셀 8px, 배지·칩은 알약 모양.
- 그림자 대신 `--border` 1px 테두리. 그림자는 지도 위에 뜨는 요소에만 쓴다.
- 간격: 4, 8, 12, 16, 20, 24px만 쓴다.
- 아이콘: 이모지(✓ ⚠ 등)를 쓰지 않고 인라인 SVG 아이콘 + 텍스트를 쓴다. 아이콘은 `aria-hidden`.
- 애니메이션: 스켈레톤 shimmer만 쓰고, 사용자가 동작 줄이기를 켰으면 멈춘다.

## 캐릭터 (나중)

- 마스코트 "환승이"(지하철 차량 앞모습 + 택시 지붕등)를 상태별 표정으로 넣을 예정이다. 그림은 아직 없다.
- 지금은 자리만 정해 둔다: 추천 카드 오른쪽, 로딩·오류·제시간 도착 불가 카드 왼쪽. 그림이 없어도 레이아웃이 깨지지 않아야 한다.
- 표정 종류: idle, happy(추천 있음), loading, late(제시간 도착 불가), error.
- 마스코트는 장식이다. 상태의 의미는 항상 텍스트로도 전한다.
