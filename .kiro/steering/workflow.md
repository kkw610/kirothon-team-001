# 팀 작업 규칙 (4인, 7시간 해커톤)

## Spec 작성 규칙
- design.md에는 반드시 **"생성/수정할 파일 목록"** 섹션을 둔다. 팀원 간 같은 파일 수정 여부를 이 목록으로 미리 확인한다.
- 공통 파일 변경이 필요하면 design.md에 **"공통 파일 변경 요청"** 섹션을 따로 만들어 변경 내용을 적는다. 구현은 담당자가 한다.
- tasks는 하나당 30분 이내로 끝나는 작은 단위로 나눈다.
- 데모 시나리오(product.md)에 필요한 것부터 구현한다. 범위 밖 기능은 제안만 하고 구현하지 않는다.

## 작업 방식
- 핵심 기능(데모의 하이라이트, 여러 파일에 걸치는 기능)만 Spec, 나머지(CRUD, UI 수정, 버그)는 Vibe로 처리한다.
- 정해진 명령(설치, git, 빌드)은 AI가 아닌 사람이 직접 실행하는 것을 기본으로 한다.
- 작업을 끝내기 전에 `npm run build`가 통과하는지 확인한다.
