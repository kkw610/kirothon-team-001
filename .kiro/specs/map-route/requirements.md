# 요구사항: 경로 지도 (map-route)

## 목적
추천 결과를 메인 화면의 결과 아래 지도에 그려서 "어느 역까지 지하철을 타고, 어디서부터 택시를 타는지"를 한눈에 보여 준다.

## 범위
- 포함: 결과 화면의 지도 자리(`ResultView`의 `aside`)에 `KakaoMap` 배치, 지하철 선, 실제 도로 모양의 택시 선, 마커 3종, 지도 범위 자동 맞춤, JS 키 환경변수 이름 정리.
- 포함(테스트): 순수 함수(`buildMapProps`, 택시 경로 변환)의 단위 테스트.
- 제외: 별도 `/map` 페이지와 쿼리 파라미터 처리.
- 포함(2단계): 지하철 선을 노선별 색으로 그리기(아래 "노선 색상").
- 범위 밖 제안: 대중교통 API의 노선 그래픽 데이터로 지하철 선로 모양 그리기, 환승역 후보 전체 표시, 마커 정보창.

## 사용자 스토리
- 사용자로서, 추천 결과를 받은 화면에서 바로 지하철 구간과 택시 구간을 서로 다른 선으로 보고 싶다. 그래야 어디서 갈아타는지 바로 알 수 있다.

## 인수 조건
1. 메인 화면에서 추천 결과가 나오면 결과 화면의 지도 자리(현재 "지도는 준비 중이에요" 자리표시)에 지도가 표시된다.
2. 추천(`best`)이 있으면 다음을 그린다. `best`가 `null`이면 가장 빨리 도착하는 옵션을 같은 방식으로 그린다.
   - 지하철 선: 경로 정류장 중 출발지부터 환승역까지의 역 좌표를 이은 선(1단계는 파란색 한 가지, 2단계에서 노선별 색).
   - 택시 선: 환승역에서 목적지까지 카카오모빌리티 길찾기 응답의 `vertexes`로 만든 도로 모양 선(주황색).
   - 마커: 출발, 환승역, 도착.
3. 택시 경로 호출이 실패하면 환승역과 목적지를 직선으로 이어 대신 그린다(점선).
4. 지도 범위는 선과 마커가 모두 보이게 자동으로 맞춘다.
5. 지도 SDK 로드에 실패하면 지도 자리에 안내 문구를 보여 주고, 나머지 결과 화면은 그대로 동작한다.
6. `KAKAO_REST_API_KEY`는 서버에서만 쓴다. 지도용 JavaScript 키만 브라우저에 노출한다.
7. 지도용 JS 키 환경변수는 `NEXT_PUBLIC_KAKAO_JS_KEY` 하나만 쓴다. 기존 `KAKAO_JS_KEY`는 `.env.example`, `src/shared/env.ts`, steering 문서, 코드 주석에서 모두 없앤다.
8. 추천 결과를 지도용 데이터(지하철 좌표, 마커, 대상 옵션)로 바꾸는 계산은 `app/`이 아니라 `src/features/map`의 순수 함수에 둔다.

## 노선 색상 (2단계)
데이터: 대중교통 연동(B)이 `Stop.line`(예: "수도권2호선", "수도권 9호선(급행)")을 채워 준다. 환승역은 먼저 탄 노선으로 표기된다.
9. 지하철 선은 `Stop.line`이 바뀌는 지점에서 구간을 나눠 구간마다 그 노선의 색으로 그린다. 구간들은 끊기지 않고 이어진다(환승역 좌표를 두 구간이 공유한다).
10. 색은 1~9호선 공식 노선색을 쓴다. `line`이 없거나 1~9호선으로 해석되지 않으면 기본 색(회색)을 쓴다. 급행 표기와 "수도권" 접두어는 무시한다.
11. 지도 안에 경로에 쓰인 노선의 범례(노선 이름과 색)를 보여 준다.
12. 택시 선은 노선 색과 구분되어야 한다. 3호선(주황)과 현재 택시 색(주황)이 비슷하므로 2단계에서 택시 선의 색 또는 선 스타일을 조정한다.

## 선행 조건 (사람이 직접)
- 카카오 개발자 콘솔 [앱] > [앱 설정] > [앱] > [플랫폼 키]에서 JavaScript 키를 확인하고, 그 키의 JavaScript SDK 도메인에 `http://localhost:3000`과 **Vercel 배포 주소**를 둘 다 등록한다. 등록하지 않은 도메인에서는 지도가 뜨지 않는다.
- 콘솔에서 카카오맵 사용 설정이 필요한지 확인하고 필요하면 켠다. 도메인을 등록해도 지도가 안 뜨면 이 설정을 먼저 본다.
- `.env.local`과 Vercel 환경변수에 `NEXT_PUBLIC_KAKAO_JS_KEY`를 넣는다. 이 값은 빌드할 때 번들에 들어가므로, Vercel에서 값을 넣거나 바꾼 뒤에는 재배포해야 반영된다.
